# 把表演写进 Prompt

Prompt as Direction · PE

把“自然、亲密、有电影感”转译成模型能够执行、创作者能够检查的镜头信息。

## 参考有各自的职责

分别绑定身份、服装、空间、起始状态、运动和声音；避免把参考图里无关的人物或表情一起带入。

## 行为具体，运镜有动机

描述谁接收到什么，如何回应，手、眼神、道具与距离怎样变化。摄影区分位置路径、观察方向、焦点、开始原因和停住位置。

## 入口与出口可以核对

写下动作开始时的真实状态和计划出口。下一镜接续的是审核过的成片出口，而不是尚未发生的设想。

## 使用模板

```text
References: identity / wardrobe / location / actual start state.
Start: positions, gaze, hands, props and current activity.
Trigger: the exact user-selected meaning.
Performance: visible reception, response, action and aftermath.
Speech: exact dialogue, speaker, delivery and pauses.
Camera: position/path, target, focus, start and endpoint.
End: hands, distance, objects and continuing activity.
Protect: this shot’s specific continuity constraints.
```
