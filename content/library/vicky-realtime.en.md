# Realtime Direction

Connect audience input to writing, directing, generation and review, making the response visible on screen and preserving evidence from each test round.

## Turn input into a visible response

Distinguish realtime inserts within a scripted story from open-ended continuation. Begin each round by interpreting user intent, then stage a response, performance and next action.

## Preserve continuity with actual state

Provide the director with character context, actual story history, scene and asset state. Encode essential constraints in structured plans and execution checks rather than relying on reminders alone.

## Review visuals, intent and waiting time together

Log visual issues, fulfillment of user intent, generation latency and the viewing experience. Choose duration and concurrency for the content using measured results, preserving versions and comparison conditions.
