# 让角色自己推动故事

Narrative Momentum · Skill

把角色欲望、主动行动与选择后果连接起来，减少机械顺从和重复拉扯，让多轮互动持续有变化。

## 把人设形容词变成行动

明确角色现在要什么、为什么此刻行动、惯用什么策略、什么会让他改变策略。角色在回应用户时仍有自己的动机与知识边界。

## 用后果制造新的局面

事件需要前提、动机、行动、介入点和完成条件。承接之前选择的后果，兑现铺垫的期待；关系改变后不靠失忆或重复误会重置。

## 同时验证主动性与选择差异

检查用户输入很少时故事是否仍能推进，以及用户认真表达时是否出现不同结果。区分文本推演、视频生成、动态审片与实际用户测试。

## 使用模板

```text
角色当前目标与策略：
继承的事实 / 承诺 / 未完成行动：
主动事件与触发条件：
用户介入点：
可见后果与情绪回报：
低输入 / 拒绝 / 新方向的回应：
状态变化与验证证据：
```
