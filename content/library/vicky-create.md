# 从灵感到可玩体验

Vicky Create · Skill

把视觉、互动、声音、个人结果与交付验证放进同一条创作流程。

## 先定义体验，再搭界面

先明确进入情境、用户动作、即时反馈与最终结果。围绕一个核心乐趣，形成 Hook → 动作 → 反馈 → 状态变化 → 个人结果的体验链。

## 让画面、声音和交互属于同一个世界

从真实资产出发建立材质、光线和运动节奏。生成、预览、保存和分享使用同一份结果，避免“看得到却带不走”。

## 从第一版考虑交付

移动视口、安全区、生命周期、双语、素材和 QA 判据同时进入第一版。局部改进沿着已确认的作品继续。

## 使用模板

```text
项目：

本轮可观察的验收标准：
```
