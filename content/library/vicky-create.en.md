# Vicky Create

Bring visuals, interaction, sound, personal outcomes and delivery checks into one creative process.

## Define the experience before the interface

Define the entry situation, user action, immediate feedback and final outcome. Build around one core pleasure: hook → action → feedback → state change → a personal result.

## Make visuals, sound and interaction belong to one world

Use real assets to establish materials, lighting and motion. Generation, preview, saving and sharing should all use the same result, so visitors can take away what they see.

## Design for delivery from the first version

Consider mobile viewports, safe areas, lifecycle behavior, bilingual content, assets and QA criteria from the first version. Improve the work while preserving what has already been approved.
