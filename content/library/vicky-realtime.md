# 让一句话接成下一场戏

Realtime Direction · Skill

把观众输入接入编剧、导演、生成与复核链路，让回应真正发生在画面里，并保留每轮测试依据。

## 把输入变成可见的回应

分清预设剧情中插入实时片段与开放式续演两种链路。每轮从理解用户意图开始，组织回应、演绎与下一步行动。

## 用真实状态保持连续

角色资料、已发生的剧情、场景和素材状态一起进入导演层。把关键约束落实到结构化计划与执行校验，避免只靠提示词提醒。

## 把画面、意图和等待一起复盘

逐轮记录画面问题、用户意图是否兑现、生成耗时与实际观看效果。时长和并发方案按当前内容及实测选择，保留版本与对比条件。

## 使用模板

```text
链路：预设插入 / 开放续演
当前角色与场景状态：
用户输入与实际意图：
本轮可见回应 / 行动 / 后续钩子：
生成方案与耗时口径：
实际视频结果与错误：
下一轮继承的已确认状态：
```
